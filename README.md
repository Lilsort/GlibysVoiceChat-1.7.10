# Gliby's Voice Chat 1.7.10 (Modernized Build)

Modernized and fixed source code for **Gliby's Voice Chat** on Minecraft 1.7.10.

---

## 🎙️ Overview

Gliby's Voice Chat provides proximity-based in-game voice communication with realistic 3D positional audio.

### 🔧 Fixes & Modernization

- Ported to the **RetroFuturaGradle (RFG 2.0.3)** build system by GT New Horizons.
- Updated compatibility for modern Java 8+ development and build environments.
- Bundled JSpeex audio compression codec (`lib/jspeex.jar`).
- Fixed sound engine hooks and Access Transformers (`gvc_at.cfg`).

---

## 🛠️ Building

```bash
git clone https://github.com/Lilsort/GlibysVoiceChat-1.7.10.git
cd GlibysVoiceChat-1.7.10
./gradlew assemble
```
